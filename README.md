# Telegram-бот для публикации вакансий

Полнофункциональный Telegram-бот для размещения вакансий и поиска исполнителей с системой анкетирования, рейтингов и автоматических уведомлений.

## 🚀 Возможности

### Для работодателей:
- ✉️ Публикация вакансий (долгосрочные и разовые)
- 📋 Управление своими вакансиями
- ✏️ Редактирование опубликованных вакансий
- 👥 Выбор кандидатов (основные + резервные)
- ⭐ Оценка работников после выполнения

### Для работников:
- 📝 Создание и редактирование анкеты
- 📨 Отклик на вакансии
- ✅ Подтверждение выхода на работу
- 📊 Просмотр своего рейтинга и статистики
- 🔔 Автоматические напоминания о работе

### Системные функции:
- 🤖 Автоматические уведомления (за 4 часа и 45 минут)
- 🚫 Система черного списка (3 отказа = блокировка на 30 дней)
- 📈 Система рейтингов с учетом отказов
- 📝 Логирование всех действий
- 👨‍💼 Админские команды для управления

## ⚙️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd telegram-job-bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Токен бота (получить у @BotFather)
BOT_TOKEN=your_bot_token_here

# База данных (PostgreSQL для продакшена, SQLite для разработки)
DATABASE_URL=postgresql://user:password@localhost:5432/jobbot
# или для SQLite:
# DATABASE_URL=sqlite:///./bot_database.db

# ID канала для публикации вакансий
CHANNEL_ID=-1001234567890
CHANNEL_URL=https://t.me/your_channel

# ID группы для анкет
RESUME_GROUP_ID=-1001234567890
RESUME_THREAD_ID=1023

# Топики для разных типов вакансий
REGULAR_THREAD_ID=1195    # Долгосрочные вакансии
PART_JOB_THREAD_ID=1      # Разовые работы

# Администраторы (через запятую)
ADMINS=123456789,987654321
ADMIN_USERNAME=your_admin_username
```

### 4. Инициализация базы данных

База данных создается автоматически при первом запуске.

### 5. Запуск бота

```bash
python bot.py
```

## 🗄️ База данных

Бот использует SQLAlchemy ORM со следующими таблицами:

- **users** - Пользователи и их анкеты
- **jobs** - Вакансии
- **job_responses** - Отклики на вакансии
- **ratings** - Оценки работников
- **resumes** - Анкеты (для совместимости)
- **action_logs** - Логи действий

## 📋 Команды бота

### Для всех пользователей:
- `/start` - Запуск бота, главное меню
- `/my_profile` - Просмотр и редактирование анкеты
- `/my_rating` - Просмотр рейтинга и статистики
- `/my_vacancies` - Список моих вакансий

### Для администраторов:
- `/logs [vacancy_id]` - Просмотр логов вакансии
- `/user_info [user_id]` - Информация о пользователе
- `/blacklist` - Список заблокированных пользователей
- `/unblock [user_id]` - Разблокировать пользователя
- `/stats` - Общая статистика системы

## 🔄 Логика работы

### 1. Создание вакансии
1. Работодатель выбирает тип (долгосрочная/разовая)
2. Заполняет 6 полей: описание, адрес, требования, оплата, график, количество людей
3. Вакансия публикуется в соответствующий топик канала

### 2. Отклик на вакансию
1. Работник нажимает "Откликнуться"
2. Если анкеты нет - заполняет анкету
3. Отклик отправляется работодателю и админу

### 3. Выбор кандидатов
1. Работодатель выбирает до N основных кандидатов
2. Дополнительно до 4 резервных кандидатов
3. Выбранным отправляется уведомление

### 4. Подтверждение работы
1. Кандидат подтверждает выход и указывает время
2. За 4 часа и 45 минут до работы - напоминания
3. После работы - запрос оценки у работодателя

### 5. Система рейтингов
- Начальный рейтинг: 5.0
- Каждый отказ: -0.3 к рейтингу
- 3 отказа = блокировка на 30 дней
- Минимальный рейтинг: 1.0

3. При необходимости обновите модели в `database/models.py`
